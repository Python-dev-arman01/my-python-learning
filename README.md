# Python Recursion Examples

यह रिपॉजिटरी पायथन (Python) में **रिकर्शन (Recursion/पुनरावृत्ति)** को समझने के लिए 4 अलग-अलग कोड उदाहरणों का एक संग्रह है। इन कोड्स के माध्यम से फैक्टोरियल, समेशन, काउंटडाउन और सबट्रैक्शन के लॉजिक को समझाया गया है।

## 📋 कोड सूची और उनका आउटपुट (Code List & Outputs)

### 1. Code 1: फैक्टोरियल (Factorial)
यह प्रोग्राम रिकर्शन का उपयोग करके किसी संख्या का फैक्टोरियल (जैसे: 5! = 5 × 4 × 3 × 2 × 1) निकालता है।

*   **इनपुट:** `5`
*   **आउटपुट:** `120`

### 2. Code 2: रिकर्सिव सबट्रैक्शन (Recursive Subtraction)
यह प्रोग्राम बेस केस तक जाने के बाद वापस आते समय संख्या को परिणाम में से घटाता है।

*   **इनपुट:** `5`
*   **आउटपुट:** `-13`

### 3. Code 3: काउंटडाउन (Countdown Series)
यह प्रोग्राम दी गई संख्या से लेकर 1 तक उल्टी गिनती (Countdown) प्रिंट करता है। फ़ंक्शन कोई वैल्यू रिटर्न नहीं करता, इसलिए अंत में `None` प्रिंट होता है।

*   **इनपुट:** `5`
*   **आउटपुट:**
    ```text
    5
    4
    3
    2
    1
    None
    ```

### 4. Code 4: संख्याओं का जोड़ (Sum of N Numbers)
यह प्रोग्राम 1 से लेकर दी गई संख्या तक की सभी संख्याओं का योग (Sum) निकालता है (जैसे: $1 + 2 + 3 + 4 + 5$)।

*   **इनपुट:** `5`
*   **आउटपुट:** `15`

## 🚀 इस प्रोजेक्ट में क्या है? (Project Features)
इस सिंगल स्क्रिप्ट कोड में मैंने पायथन के निम्नलिखित मुख्य कॉन्सेप्ट्स का उपयोग किया है:
1. **`with open()` स्टेटमेंट:** सुरक्षित तरीके से फ़ाइल को हैंडल करने के लिए (ताकि फ़ाइल ऑटो-क्लोज हो सके)।
2. **File Modes:** फ़ाइल में लिखने के लिए `w` (Write), नया डेटा जोड़ने के लिए `a` (Append), और डेटा पढ़ने के लिए `r` (Read) मोड का इस्तेमाल।
3. **String Replacement:** गलत स्पेलिंग्स को ठीक करने के लिए `.replace()` मेथड का उपयोग।
4. **Method Chaining:** कोड को छोटा और कुशल बनाने के लिए एक साथ कई `.replace()` का उपयोग।
5. **Data Splitting:** फ़ाइल के टेक्स्ट को शब्दों की लिस्ट में बदलने के लिए `.split()` का उपयोग।
